# Contributing

Guildwake is Apache-2.0, copyright 2026 gdragon-git. Contributions submitted for
inclusion use the project's license unless explicitly stated otherwise, consistent
with the license's contribution terms. Preserve required third-party notices.
Do not submit private configuration, identities, keys, tokens, saves or logs.

Use GitHub issues/pull requests for improvements and SECURITY.md for sensitive
reports. Keep the narrow capability model: role-based status/wake/Enshrouded start,
private results, complete observer coverage, conservative unknowns and no automatic
mutation replay. Public tests use synthetic installations and substituted effects.

Run the affected portable tests and package checks. Preserve failures, explain
the correction, and distinguish fixtures from Linux/installed/live proof. Do not
contact a contributor's real Discord/AMP/server from a default test. Keep optional
HTTP/A2S migration, web UI and additional games separate from the first profile.
